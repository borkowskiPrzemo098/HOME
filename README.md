# 🚀 Moje Projekty — HOME

Prosta, mobilna strona typu "hub" do wszystkich Twoich projektów (aplikacji i stron www).

## Funkcje
- Idealne skalowanie na telefon (mobile-first)
- Zakładki: Wszystko / Aplikacje / Strony
- Kliknięcie w kartę projektu otwiera go w nowej karcie
- Dodawanie nowych projektów przyciskiem **+** (dane trzymane w `localStorage` przeglądarki)
- Usuwanie projektu przyciskiem ✕ na karcie
- Dolne menu nawigacyjne (jak w aplikacjach mobilnych)
- Efekty 3D na kartach, animacje, przejścia

## Użycie
Otwórz `index.html` w przeglądarce (lokalnie) lub hostuj przez GitHub Pages.

### GitHub Pages
1. Wejdź w ustawienia repo → Pages
2. Źródło: branch `main`, folder `/ (root)`
3. Strona pojawi się pod adresem `https://<user>.github.io/<repo>/`

## Dane
Projekty są zapisywane lokalnie w przeglądarce (localStorage), nie na serwerze — każde urządzenie ma swoją własną listę, chyba że dodasz backend.
